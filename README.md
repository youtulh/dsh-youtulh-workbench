# Youtulh 工作台

DeepSeek Harness 的一个插件。给做内容的人用的一台工作台：一句话记选题，一键出成稿，粘一条私信就分诊，做完回来看数据。

## 安装

需要 DeepSeek Harness 0.2.x（`engines.dsh` 要求 `>=0.2.1-rc.5 <0.3.0`）。

两种装法，任选一种：

- **从 npm**：打开 DSH 的 **插件** 页 → 安装插件 → 输入 `dsh-youtulh-workbench`
- **从 GitHub**：插件页 → 安装插件 → 输入 `github:youtulh/dsh-youtulh-workbench`

装完在侧栏会出现「Youtulh 工作台」。

## 六个页面

| 页面 | 做什么 |
|---|---|
| 灵感 | 文字、链接、图片、视频、金句都是一张卡。可以记「卡点」和拍摄进度（待拍 / 已拍 / 已发），点一下标签就往下走一格 |
| 私信 | 粘一条家长私信 → 判断「是谁、问什么」→ 出两条草稿（一条接住、一条引导下一步）→ 台账七个字段自动抽出来 → 存进线索表 |
| 内容 | 成稿工作区：标题、脚本、封面、配图、六格分镜一起长出来。左边说一句，右边就改，每一步能撤销 |
| 排期 | 把做完的稿子拖到日历上排期 |
| 复盘 | 录播放、私信、加微、约试听，看两张榜：什么内容传得开，什么内容真带人 |
| 风格 | 最上面是**定位卡**（只做 / 不做 / 说法 / 红线），下面是从自己账号抓出来的写作风格和写作规则 |

## 会一起用到的几个东西

**定位卡**：填一次，管住三处 —— 出选题时只在「只做」里挑、成稿时的说法跟着「说法」走、私信话术不碰「红线」。

**发布包**：成稿做好之后，标题下面会多一块发布三件套（小红书短标题、话题标签、三平台说明文案），一个按钮复制整张纸。点保存时文件夹里还会多写一份 `发布包.txt`，含标题、短标题、标签、说明和发布顺序 —— 拿到就能发，不用回头问。

**线索表**：私信分诊完存一行，七个字段是 姓名 / 年级 / 学校 / 卡点 / 来源 / 下一步。下一步点一下循环，整张表可以复制成 CSV。

界面有中文和英文，默认跟随 DSH 的语言。数据存在本机 `~/.dsh/media-desk/state.json`，桌面端和网页端读同一份。保存成稿时写到 `~/Documents/Youtulh 工作台/`。

## 开发

```bash
node scripts/build.mjs          # 把 client/ 打包成 dist/client.js
node scripts/build.mjs --watch  # 改界面时挂着跑，然后刷新页面
node --test test/*.test.js      # 测试
```

`client/` 是界面源码（JSX），`src/` 是宿主半边（Node ESM），`dist/client.js` 是构建产物、不入库。

改界面：构建 → 刷新页面即可。改 `src/`：重新装一次插件或用插件开关热重载。
