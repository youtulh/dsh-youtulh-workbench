# Youtulh 工作台

DeepSeek Harness 的一个插件。给线上带小班的老师用的一台推流工具：**回私信、做内容、看数据**。它不藏数据 —— 你生成的东西全部写成你电脑上的文件，Word 能打开，Excel 能打开，随时能改。

## 安装

需要 DeepSeek Harness 0.2.x（`engines.dsh` 要求 `>=0.2.1-rc.5 <0.3.0`）。

- **从 npm**：DSH 的 **插件** 页 → 安装插件 → 输入 `dsh-youtulh-workbench`
- **从 GitHub**：插件页 → 安装插件 → 输入 `github:youtulh/dsh-youtulh-workbench`

装完在侧栏会出现「Youtulh 工作台」。

## 第一次打开：先做问卷

一屏一个问题，**每题都能自己写**（选项里没有的科目、年级、情况直接填）：

1. 教什么科目 · 带哪个年级 · 在哪个城市
2. 学生主要是哪种情况 · 你不想接哪种
3. 家长最常跟你说的一句话

最后一屏是「这是你的定位」，确认后写进 `我的设定.md`，停留在**「设定已保存」**这一屏 —— 想去写口播就点「去做第一条口播」，不想就留在首页。

之后首页是一条三步工作流：认识你 ✓ → 做第一条口播 → 回私信、看数据。

## 三个动作

三个动作都在页面里完成，不需要跳来跳去。写稿和分诊用的模型跟着 DSH 当前助手模型走；模型没通时会有明确提示，不会悄悄换成模板。

| 动作 | 你在页面上做什么 | 结果落在哪 |
|---|---|---|
| **做内容** | 出 10 个选题（带「知识点 / 家庭 / 考情 / 本地」角度标签）→ 勾选 → 每个选题出 3 个口播版本 → 点「采用这条」 | `内容/<日期 标题>/` 的 `.docx` + `.md`；`内容库.csv` 记一行 |
| **回私信** | 粘一条家长私信 → 「判断一下」：是谁、问什么、两条话术（第二条引导加微信）→ 挑一条改成自己的 → 「记进线索表」 | 线索表追加一行（含话术）；话术可以回头改 |
| **看数据** | 粘贴后台数据（认「作品名称 / 播放量 / 新增粉丝」等列名，对不上的自动补一条），或「补录一条」以前发过的视频 | `内容库.csv`：播放 / 涨粉 / 私信 / 加微，按 未发布 / 已发布 / 爆款 筛选 |

「采用这条」之前不会写任何文件、也不会进内容库。切到别的页面再回来，这一批选题和口播都还在（刷新也在）。

另外还有：**我的产出**（列工作区里的真实文件夹）、**我的设定**（编辑 `我的设定.md`，也可以直接在编辑器里改文件；页面保存时不会覆盖你手改的其它字段）。想深聊就点回私信页的「去对话里深聊」，日常不用跳。

## 你的数据在哪

```
~/Documents/Youtulh 工作台/
├── 我的设定.md          ← 改它，插件跟着变
├── 说话样本.md          ← 助手的口气参考，换成你自己的原话
├── 账号数据.csv         ← 平台 / 账号 / 粉丝
├── 线索表.csv           ← 私信台账：话术 / 家长反应 / 结果
├── 内容库.csv           ← 每条口播的结果：播放 / 涨粉 / 私信 / 爆款
├── 选题库.csv           ← 生成过的选题，以及你勾了哪些
├── 经验库.md            ← 插件自动写：什么内容爆了、什么话说到了微信
├── 内容/<日期 标题>/    ← 口播稿 .docx + .md
├── 私信/<日期 姓名>/    ← 判断 + 话术 + 台账
└── 数据/                ← 后台数据、复盘结论
```

路径可以在插件设置里改。文件是唯一真相来源：插件启动时读 `我的设定.md`，私信页直接读 `线索表.csv`，产出页直接列目录 —— 没有隐藏的数据库。

## 三条红线（写进每一次生成）

不承诺提分、不说包过、不报价格、不编造孩子的情况。

## 越用越好

工作台记四件事，然后拿它们反哺生成：

| 你做的动作 | 记在哪 | 下次生成时 |
|---|---|---|
| 生成 10 个选题、勾几个 | `选题库.csv` | 被采纳最多的选题方向进 prompt |
| 生成口播、标「采用这条」 | `内容库.csv` | 「采用」的选题方向会被参考 |
| 发出去以后填 播放/涨粉/私信/加微 | `内容库.csv` | 自动打分，最强的那条标爆款；开头第一句也进 prompt |
| 回私信标「已加微」 | `线索表.csv` | 成功话术进分诊参考 |

**打分**：`私信×3 + 涨粉×1 + 播放×0.001`；样本满 3 条后，分数进前 25% 自动标「爆款」，你手标的「否」优先级最高。

看数据页顶上看两个比值：**每万播私信**（内容带不带人）和**私信→加微**（话术接不接得住）。

经验块会注入到「出选题」「写口播」「回私信」三处，`经验库.md` 随时能打开看它学到了什么。

## 开发

```bash
node scripts/build.mjs          # 把 client/ 打包成 dist/client.js
node scripts/build.mjs --watch  # 改界面时挂着跑，然后刷新页面
node --test test/*.test.js      # 测试
```

`client/` 是界面源码（JSX），`src/` 是宿主半边（Node ESM），`dist/client.js` 是构建产物、不入库。

**踩坑记录**：每次在插件管理里切换安装方式（link ↔ npm），本仓库的 `node_modules` 会被清掉，构建会报 `Cannot find package 'esbuild'`。解决：

```bash
pnpm install && node scripts/build.mjs
```

Word 导出（`src/word.js`）不依赖任何第三方库：手写 zip 容器 + WordprocessingML，macOS 的 `textutil` 和 Word 都验证过能读。
