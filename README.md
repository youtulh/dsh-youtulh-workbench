# Youtulh 工作台

DeepSeek Harness 的一个插件。给线上带小班的老师用的一台推流工具：**聊天台、做内容、看数据**。它不藏数据 —— 你生成的东西全部写成你电脑上的文件，Word 能打开，Excel 能打开，随时能改。

## 安装

需要 DeepSeek Harness 0.2.x（`engines.dsh` 要求 `>=0.2.1-rc.5 <0.3.0`）。

- **从 npm**：DSH 的 **插件** 页 → 安装插件 → 输入 `dsh-youtulh-workbench`
- **从 GitHub**：插件页 → 安装插件 → 输入 `github:youtulh/dsh-youtulh-workbench`

装完在侧栏会出现「Youtulh 工作台」。

## 第一次打开：先定一类家长

先讲清楚这门生意：你要的不是粉丝，是一个能加微信的家长；上课厉害不等于招生厉害，招生是家长付费前那几步。平台也不会直接给你精准家长，人群是靠内容一条一条洗出来的。

然后一屏一个问题，**每题都能自己写**：

1. 教什么科目 · 带哪个年级 · 在哪个城市
2. 学生主要是哪种情况（含偏科）· 你不想接哪种
3. 家长最常跟你说的一句话
4. **先只抓哪类家长**：按你的学生情况排好顺序的 4 张卡（中等生 / 偏科 / 尖子 / 基础差但家长还在想办法 / 艺考），选一张，或者自己写
5. 补三句：**我为谁、从哪切进去、她最怕什么**

最后一屏是定位一句话（我是谁 + 我为谁 + 解决什么问题）；确认后写进 `我的设定.md`，停在「设定已保存」——下面直接给你**第一批四条可拍的视频**（科目 / 家庭 / 考情 / 本地），点一条就去做内容，选题已经勾好。

之后首页是一条四步工作流：认识你（含目标客户）→ 做第一条口播 → 聊天台、看数据 → 报课之后（转学生、建班、记每次课）。还没定目标客户时，首页会提示你补。

## 定位复盘

设定不是填一次就放着的。「我的设定 → 定位复盘」会拿最近 30 条内容和全部线索回看：

- 内容贴不贴定位（科目/年级/切入点）；
- 线索年级对不对得上；
- 哪条内容带来的家长最多、哪条转化最好；
- 内容配比（知识点 / 家庭 / 考情 / 本地）；
- 直接给 3 个下一步能拍的选题，点一条就进做内容。

## 四个动作

四个动作都在页面里完成，不需要跳来跳去。写稿和分诊用的模型跟着 DSH 当前助手模型走；模型没通时会有明确提示，不会悄悄换成模板。

| 动作 | 你在页面上做什么 | 结果落在哪 |
|---|---|---|
| **做内容** | 想好了就写一句「想讲什么」→ 直接出 3 版草稿；没想好就出 10 个选题（带「知识点 / 家庭 / 考情 / 本地」角度标签）→ 勾选 → 每个选题出 3 个口播版本 → 每版自带**评论区置顶**和**私信第一句** → 「改一下」就地改稿，或写一句「想怎么改」按提示重写这组 → 点「采用这条」 | `内容/<日期 标题>/` 的 `.docx` + `.md`；`内容库.csv` 记一行（含角度、评论区、私信引导） |
| **聊天台** | 选「平台私信 / 微信」→ 粘对方最后一句 → 给两条下一句（平台阶段一两句挪走私信，不报价；微信阶段给判断、约诊断/试听）→ 挑一条发出去、顺手「记一笔」；「最近对话」里能接着上一轮聊、能标成交/流失，也能导入人工聊天案例 | `对话记录.csv` 记每一轮；`案例库.csv` 存人工案例；线索表照旧追加 |
| **看数据** | 粘贴后台数据（认「作品名称 / 播放量 / 新增粉丝」等列名，对不上的自动补一条），或「补录一条」以前发过的视频 | `内容库.csv`：播放 / 涨粉 / 私信 / 加微，按 未发布 / 已发布 / 爆款 筛选 |
| **学生** | 线索漏斗拖阶段 → 报课了「转成学生」→ 建班（期次 / 名单 / 8 次课 / 本班分层）→ 每次课点出勤、掌握、作业；班结束了点「结课」归档，默认只列在读的班 | `学生档案.csv`、`班课.csv`、`课次记录.csv`；阶段直接写回 `线索表.csv` |

学生档案支持从 Excel / 表格里粘名单：第一行表头写「姓名、年级、学校、微信、卡点层、班、来源、备注」，认 Tab 和逗号，带引号的备注不会拆列；名单里提到但还没建过的班，会自动建一个空班，学生不会挂在不存在的班里。

线索漏斗也支持「导入线索」：第一行表头写「日期、姓名、年级、卡点、来源、阶段、下次跟进、原文」，认常见别名（家长 / 痛点 / 话术等），粘完直接进线索表。

每条口播会标「约 xx 秒 · xxx 字」（按每秒 4.2 个字估），复制可以只复制标题或复制全文。看数据里有「内容库 / 工作区文件」两个 tab，文件和文件夹都归在这一页，不用再切出去。

聊天台分两个阶段：**平台私信**只负责一两句话把人挪走私信（不报价、不展开讲），**微信**里才给判断、约诊断或试听。下一句不满意可以「再给一版」；发出去前改过的句子会标「已改」，记一笔时留痕。最近对话能按渠道/结果/人筛、标成交或流失，标成交会顺手把线索推到已报课、并建学生档案。

聊天台的线索表能搜索、按来源筛选、按「最近 / 最该跟进 / 跟过最多 / 阶段」排序，也能按「该跟进」筛出到期没跟的人，卡片上显示拖了几天，可一键「记一次跟进」或顺延明天/3 天后。

学生档案里点「写反馈」，会按这个学生最近几次课的出勤、掌握、作业写一条能直接发微信的家长反馈；没连模型时按记录拼一条，不会编细节。写好的可以「存一笔」，以后在同一个面板里能翻到以前写过的。

「采用这条」之前不会写任何文件、也不会进内容库。切到别的页面再回来，这一批选题和口播都还在（刷新也在）。采用之后点「改一下」保存，会同步更新那篇 `内容/<日期 标题>/` 里的 Word、Markdown 和内容库。

家长微信/手机是明文存在本机 `学生档案.csv` 里的；这个文件只在你自己的电脑上，别把工作区文件夹直接发到群里。

「我的设定」里可以一键备份：把整个工作区复制到旁边的备份文件夹，原数据不动。

另外还有**我的设定**（编辑 `我的设定.md`，也可以直接在编辑器里改文件；页面保存时不会覆盖你手改的其它字段）。想深聊就点聊天台的「去对话里深聊」，日常不用跳 —— 跳过去时输入框里填的是你自己的话，不是给开发者的指令。

## 你的数据在哪

```
~/Documents/Youtulh 工作台/
├── 我的设定.md          ← 定位、目标客户、切入点、最怕什么；改它，插件跟着变
├── 说话样本.md          ← 你的口气参考：生成口播和私信话术时会读「原话样本」；在「我的设定」里能直接改
├── 账号数据.csv         ← 平台 / 账号 / 粉丝
├── 线索表.csv           ← 私信台账：话术 / 家长反应 / 结果 / 漏斗阶段 / 下次跟进 / 跟进次数
├── 对话记录.csv         ← 聊天台每一轮：渠道 / 对方说 / 我方回 / 阶段 / 结果；在「最近对话」里能补结果
├── 案例库.csv           ← 你导入的人工聊天案例：平台引流、微信成交
├── 平台词表.md          ← 平台私信能用/不能用的词；「我的设定」里能直接改
├── 学生档案.csv         ← 报课的学生：年级 / 学校 / 家长微信或手机 / 卡点层 / 在哪个班
├── 班课.csv             ← 期次、上课时间、总次数、这个班的分层
├── 课次记录.csv         ← 每次课：出勤 / 掌握 / 作业（一人一行）
├── 家长反馈.csv         ← 写过的家长反馈：日期 / 学生 / 依据几次课 / 内容
├── 内容库.csv           ← 每条口播的结果：播放 / 涨粉 / 私信 / 爆款
├── 选题库.csv           ← 生成过的选题，以及你勾了哪些
├── 经验库.md            ← 插件自动写：什么内容爆了、什么话说到了微信
├── 内容/<日期 标题>/    ← 口播稿 .docx + .md
├── 私信/<日期 姓名>/    ← 判断 + 话术 + 台账
└── 数据/                ← 后台数据、复盘结论
```

路径可以在插件设置里改。文件是唯一真相来源：插件启动时读 `我的设定.md`，私信页直接读 `线索表.csv`，学生页直接读那三张表，产出页直接列目录 —— 没有隐藏的数据库。

## 三条红线（写进每一次生成）

不承诺提分、不说包过、不报价格、不编造孩子的情况。

## 越用越好

工作台记四件事，然后拿它们反哺生成：

| 你做的动作 | 记在哪 | 下次生成时 |
|---|---|---|
| 生成 10 个选题、勾几个 | `选题库.csv` | 被采纳最多的选题方向进 prompt |
| 生成口播、标「采用这条」 | `内容库.csv` | 「采用」的选题方向会被参考 |
| 发出去以后填 播放/涨粉/私信/加微 | `内容库.csv` | 自动打分，最强的那条标爆款；开头第一句也进 prompt |
| 聊天台把线索挪到「已加微信」 | `线索表.csv` | 成功话术进分诊参考 |
| 聊天台「我发了，记一笔」/ 导入案例 | `对话记录.csv`、`案例库.csv` | 点「最近对话」里的结果（成交 / 约试听 / 加微），聊成的会进下一句建议的参考；点家长名字只看他的对话，标成交会顺手建学生档案；学生页会把「来自聊天成交」标出来 |

**打分**：`私信×3 + 涨粉×1 + 播放×0.001`；样本满 3 条后，分数进前 25% 自动标「爆款」，你手标的「否」优先级最高。

看数据页顶上看两个比值：**每万播私信**（内容带不带人）和**私信→加微**（话术接不接得住）。

经验块会注入到「出选题」「写口播」「聊天台」三处，`经验库.md` 随时能打开看它学到了什么。

学生管理这一版只做第一期：漏斗、学生档案、班课和每次课记录。诊断卷 / 课后小测自动写入卡点层和掌握情况是第二期；账号、云端、多人协作、支付、排课都不做。

## 开发

```bash
node scripts/build.mjs          # 把 client/ 打包成 dist/client.js
node scripts/build.mjs --watch  # 改界面时挂着跑，然后刷新页面
node --test test/*.test.js      # 测试
```

`client/` 是界面源码（JSX），`src/` 是宿主半边（Node ESM），`dist/client.js` 是构建产物、不入库。

**踩坑记录**：每次在插件管理里切换安装方式（link ↔ npm），本仓库的 `node_modules` 会被清掉，构建会报 `Cannot find package 'esbuild'`。解决：

```bash
pnpm install && node scripts/build.mjs
```

Word 导出（`src/word.js`）不依赖任何第三方库：手写 zip 容器 + WordprocessingML，macOS 的 `textutil` 和 Word 都验证过能读。
